# 评论系统说明

## 📌 功能概述

3D文物展示系统已集成评论功能，允许用户对每个文物模型发表评论和查看他人的评论。

## ✨ 主要特性

### 1. 评论发布
- ✅ 用户可以在评论输入框中输入评论内容
- ✅ 点击"发布"按钮提交评论
- ✅ 支持快捷键：`Ctrl + Enter` 快速提交
- ✅ 评论内容限制：最多500字
- ✅ 自动生成随机用户名（如：热心的观众1024）

### 2. 评论显示
- ✅ 评论按时间倒序排列（最新的在最上面）
- ✅ 显示评论者昵称
- ✅ 智能时间显示：
  - 1分钟内：刚刚
  - 1小时内：X分钟前
  - 24小时内：X小时前
  - 7天内：X天前
  - 超过7天：显示具体日期
- ✅ 评论区域支持滚动浏览

### 3. 数据存储
- ✅ 使用 `localStorage` 存储在浏览器本地
- ✅ 评论数据持久化保存在浏览器中
- ✅ 每个模型的评论独立存储
- ✅ 数据格式：JSON
- ⚠️ 注意：数据存储在浏览器中，清除浏览器数据会丢失评论

### 4. 安全性
- ✅ HTML内容转义，防止XSS攻击
- ✅ 输入验证和长度限制


## 💻 技术实现

### 数据结构

每条评论包含以下字段：

```javascript
{
  id: 1234567890,                      // 时间戳ID
  author: "热心的观众1024",             // 用户名
  content: "这件文物太精美了！",        // 评论内容
  timestamp: "2024-10-19T10:30:00Z",   // 时间戳
  modelPath: "teacup.gltf"             // 关联的模型
}
```

### 存储键名
```
localStorage key: 'heritageViewerComments'
```

## 🎮 使用方法

### 用户端操作

1. **发布评论**
   - 在评论输入框中输入内容
   - 点击"发布"按钮或按 `Ctrl + Enter`
   - 评论会立即显示在评论列表顶部

2. **查看评论**
   - 评论列表会自动显示当前模型的所有评论
   - 可以滚动查看更多历史评论

3. **切换模型**
   - 切换到不同文物时，会自动显示该文物的评论

### 管理员操作

在浏览器控制台（F12）中可以使用以下命令：

```javascript
// 添加测试评论（用于演示）
commentManager.addTestComments()

// 导出所有评论数据
commentManager.exportComments()

// 清空所有评论（慎用！）
commentManager.clearAllComments()

## ⚠️ 注意事项

1. **存储限制**
   - localStorage 通常限制为 5-10MB
   - 评论过多可能导致存储不足
   - 建议定期清理历史评论

2. **浏览器兼容性**
   - 需要支持 localStorage 的现代浏览器
   - IE9 及以下版本不支持

3. **数据安全**
   - 当前使用本地存储，清除浏览器数据会丢失评论
   - 未来版本将支持云端存储

4. **隐私保护**
   - 用户名为随机生成，不收集个人信息
   - 无需登录即可使用
