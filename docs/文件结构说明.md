## 📝 文件说明

### HTML页面
- `index.html` - 项目主页和导航
- `main.html` - 3D文物查看器（核心功能）
- `dynasty.html` - 按朝代浏览文物
- `gallery.html` - 文物图库
- `settings.html` - 系统设置
- `tutorial.html` - 使用教程

### 核心脚本
- `scripts/game.js` - Three.js 3D渲染和MediaPipe手势识别
- `scripts/aiAssistant.js` - 通义千问AI集成
- `scripts/ai-proxy.py` - 解决CORS的AI代理服务器
- `scripts/comments.js` - 评论和点赞系统

### 资源文件
- `assets/` - 3D模型（.gltf, .glb格式）
- `images/` - 图片素材
- `styles/` - CSS样式
- `data/` - JSON数据文件
- `media/` - 视频文件

### 文档
- `docs/` - 所有Markdown文档和说明
